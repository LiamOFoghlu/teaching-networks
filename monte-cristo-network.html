The Count of Monte Cristo: a network of characters

Kinship, marriage and love, harm, help, and Monte Cristo's revenge. Rows are roughly generations. Click a character to isolate their ties; use the legend to filter. Contains spoilers.

Hover over a line to read the relationship. Centrality is computed on the ties currently shown, treating them as undirected and counting several ties between the same pair once. Betweenness is normalised to 0–1; closeness is harmonic closeness, which still works when hiding some tie types cuts a node off.
